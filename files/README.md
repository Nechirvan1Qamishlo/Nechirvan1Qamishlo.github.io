# Files (papers, slides)

Everything in this folder is served directly by GitHub Pages, e.g.
`files/papers/2021-big-data-sustainable-performance.pdf` → https://nechirvanothman.me/files/papers/2021-big-data-sustainable-performance.pdf

## Papers
Each publication on the homepage already has a hidden "PDF ↓" link. Upload the PDF with the
matching name into `files/papers/` and the link appears by itself:

**Before uploading a published article**, check the journal's sharing policy (e.g. on Sherpa Romeo).
Many publishers don't allow the final publisher PDF to be posted, but do allow the
author-accepted manuscript. When in doubt, link the DOI instead.

## Limits
Keep each file under 100 MB (GitHub's hard limit) and the whole site under 1 GB.
For large datasets or many big files, use external storage (e.g. Cloudflare R2 or Zenodo) instead.
